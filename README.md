# Amazon E-Commerce Product Data Analysis using Python

## 📌 Project Overview

This project analyzes Amazon e-commerce product data using Python to identify patterns and generate meaningful business insights.

The analysis covers data cleaning, exploratory data analysis (EDA), product categories, customer ratings, pricing, discounts, customer engagement, and data visualization.

## 🎯 Objectives

* Clean and prepare raw e-commerce data for analysis
* Analyze product categories and sub-categories
* Understand product rating patterns
* Analyze product pricing and discounts
* Identify highly reviewed products
* Visualize important trends and patterns
* Generate meaningful business insights

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## 📊 Analysis Performed

### Data Cleaning

* Checked dataset structure
* Identified missing values
* Removed duplicate records
* Handled missing values
* Checked and converted data types
* Removed unnecessary columns

### Exploratory Data Analysis

* Statistical Summary
* Product Categories
* Average Product Rating
* Top 10 Product Categories
* Product Rating Distribution
* Product Rating Box Plot
* Top 10 Most Reviewed Products
* Category-wise Product Share
* Selling Price Distribution
* Top 10 Sub-Categories
* Discount Percentage Distribution

## 💡 Key Insights

* Product listings are concentrated in a few major categories.
* Product ratings are generally on the higher side.
* Some products receive a large number of customer ratings.
* Most products fall within low and medium price ranges.
* Discount percentages vary across products.
* A few sub-categories contain a large share of the available products.
